# v3.5.3 升级说明（2026-11-14）

本版本**无数据库结构变更**，升级只需换镜像（`./init.sh` 亦可，幂等）。

## 升级步骤

```bash
git pull
sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=3.5.3/' .env   # 老部署的 .env 还钉着旧版本号
docker compose pull && docker compose up -d
```

## 变更内容（v3.5.2 → v3.5.3）

### 修复

- **考试列表「AI批改进度」跨重启持久化**：进度原只存 Redis 且每次后端重启清空，AI 批改过的考试重启后列表全部回落「未使用」；现改为 Redis 实时态优先、数据库最近一次运行兜底——「已完成 / 已终止」跨重启持久显示，「未使用」从此如实表示从未发起过整卷 AI 批改。进度详情弹窗同口径取数；「清除批改进度」会把数据库终态落为已终止（原先只清内存态）；单条损坏的进度缓存不再拖垮整个考试列表
- **V50 迁移新库首跑执行序**（仅影响全新部署）：修复新库首次执行 V49→V50→V51 时为待删标记行误建孤儿映射的问题（已部署库重放安全无感）；若曾用 v3.5.2 做过全新部署，可按 V50 脚本头注释中 gate3 口径自查清理
- 标准版授权说明弹窗文案口径统一（「免费版已包含…」→「标准版已包含…」）

### 界面优化

- 教师端「综合管理」：授课学期 / 教学班侧栏可整体折叠，扩大主工作区视野
- 慢网环境体验：教师端与学生端路由切换时显示加载反馈，页面资源（chunk）拉取失败自动兜底处理，不再白屏等待
