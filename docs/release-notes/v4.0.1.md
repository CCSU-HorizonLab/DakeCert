# v4.0.1 升级说明（2026-11-17）

本版本**含数据库结构变更**（V52/V53：班级助教任职表 + 权限列），升级请用 `./init.sh`（幂等；已按「停应用 → 迁移 → 起新镜像」编排，停机窗口≈迁移秒级+应用启动，建议安排在非教学时段）。

## 升级步骤

```bash
git pull
sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=4.0.1/' .env   # 老部署的 .env 还钉着旧版本号
./init.sh
```

## 变更内容（v3.5.3 → v4.0.1）

### 新增：教学班「班级助教」

- **任命助教**：授课班编辑弹窗可搜索全量在册用户任命班级助教（学生/教师均可任职）；助教是任职表派生身份（非独立角色），撤销任职后即时生效
- **8 项逐人可配置权限**（checkbox 默认全选）：题库整理 / 组卷 / 试卷批改 / 试卷再次批改 / 已批改导出 / 课堂签到管理 / 成绩分析（学情查看）/ AI 初评（AI 初评仅部署了 AI 批改组件的授权版有实际入口，标准版勾选亦无害）
- 试卷**发布 / 排期 / 删除**按产品口径不授予助教
- 权限清单注册表化：后续增减权限项只改清单，无需散改各处代码

### 安全加固

- 助教权限守卫改为数据库任职实时校验——撤销任职后原 token 立即失效
- 成绩相关接口按考试锚定校验；已批改导出逐考试鉴权，空集拒绝全库导出
- 考试列表服务端定界（按名册班 ∪ 助教班），不再信任前端参数
- 学生答题与成绩链路对学生助教保守拒绝（fail-closed）

### 修复

- 学生助教在未匹配到大纲路由前不再误跳【课程测验】
- 签到管理课程选择器以课程名称显示（替代课程 ID 数字）
- 助教任职列表载入失败时跳过提交，防止误清全班助教配置

### 数据库迁移（幂等可重跑）

- **V52**：班级助教任职表 `em_teaching_class_assistant`（老库新增；全新安装种子已含表结构则空跑）
- **V53**：任职表新增 `permissions` 列（NULL=全部 / 空=无 / 逗号分隔=显式授予集）
