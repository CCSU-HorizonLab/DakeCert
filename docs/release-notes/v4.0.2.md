# v4.0.2 升级说明（2026-11-20）

本版本**无数据库结构变更**，升级即换镜像：`./init.sh` 照常幂等（迁移目录无新文件，自动空跑）。

## 升级步骤

```bash
git pull
sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=4.0.2/' .env   # 老部署的 .env 还钉着旧版本号
./init.sh
```

## 变更内容（v4.0.1 → v4.0.2）

本版主题：**Word 文书模板引擎保存正确性根治与全链防丢 + 安全定界 + 空数据降级**。涉及四类共用文书：教学大纲 / 考试命题计划表 / 课程考核审核表 / 达成度评价报告。

### 模板编辑器·保存正确性（本版核心）

- 保存管线重写为段落级对齐：**段末插入的内容不再漂移到下一段开头**、**整段重写不再新旧并存**；支持清空段落、空单元格输入、回车拆段
- 界面不可见的文档段落保守保留，不再误改丢内容
- 系统值（课程名/学期等）根治：课程改名或更换学期后，渲染与导出均为当前值，不再带出旧值
- 保存过程中继续输入的内容不再被保存基线吞掉（此前表现为保存后红点消失、关页无声丢失）
- AI 撤销不再「假成功」；命题表难度勾选框预填归一（不再恒显未勾、导出不再出现 true/false 字面量）
- 已定稿（LOCKED）大纲的编辑预检补单列判定，不再误放行

### 模板编辑器·防丢与体验

- 防丢三件套：填写脏标记红点 / `Ctrl+S` 保存 / 关页拦截确认；保存成功显示「已保存 HH:mm」，再编辑即被红点取代
- 导出前检查闭环：先列出未填变量，「去填写」一键定位；全部填完后导出不再打扰
- 待填导航驻留（当前项高亮、填完自动推进）；页宽缩放（自适应/100%/75%）；「?」图例气泡
- AI 改写助手：改写风格一步化、插入后 5 秒撤销窗（AI 能力仅部署了 AI 批改组件的授权版有实际入口，标准版无碍）
- 上传覆盖确认、变量容量溢出常驻警示 + 一键扩容指路、自定义模板缺失自动回退默认模板

### 安全与定界

- 课堂签到记录（含个人信息）读取收敛：管理端全量 / 教师按自建∪任课∪助教班 / 学生按名册，不再任意登录用户可枚举
- 试卷修改/删除鉴权收敛为统一口径
- 修复 v4.0.1 引入的回归：专业负责人/院系管理员的考试列表被清空

### 稳定性

- 大纲未配置考核环节时，达成度四个页面显示空态指路（不再白屏/报错）；历届对比按「该届不可用」标记
- 班级助教载入失败即时警示（不再保存后才报错）；任职列表翻页修复（第 101+ 名助教不再被隐性撤销）
- 其余约 40 项体验优化
