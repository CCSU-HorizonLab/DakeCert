# v3.5.2 升级说明（2026-11-12）

## ⚠️ 本版本含数据库结构变更，升级由 init.sh 自动编排

新增 `database/migration/` 目录，包含三项幂等迁移：

| 迁移 | 内容 |
|---|---|
| **V49** | `exam` 表新增 `forbid_code_copy` 列（代码题禁复制粘贴开关） |
| **V50** | 新增 `em_course_examine_detail_goal` 映射表：课程目标分配关系从考核明细行迁入独立表（本次核心修复） |
| **V51** | 退役 `em_course_examine_detail.goal_id` 列（分配事实自 V50 起唯一存映射表，该列已无读点） |

### 升级步骤（推荐）

```bash
git pull
sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=3.5.2/' .env   # 老部署的 .env 还钉着 3.5.1
docker compose pull
./init.sh                                        # 幂等：自动补跑迁移并拉起新镜像
```

### 手动迁移（备选）

```bash
docker compose stop app                           # V51 含删列，旧应用对已删列查询会 500，迁移前先停
for f in database/migration/*.sql; do
  docker compose exec -T postgresql psql -U postgres -d dake -v ON_ERROR_STOP=1 < "$f"
done
docker compose pull && docker compose up -d
```

> 顺序务必「先停应用、再迁移、后起新镜像」：V51 起含删列等破坏性变更，旧镜像的
> 代码仍按旧列清单查询，列被删除后接口会报错；`./init.sh` 已按此顺序自动编排，
> 手动迁移也务必遵守（停机窗口约 1-2 分钟，请安排在非教学时段）。
> 三个迁移脚本均可重跑（`IF NOT EXISTS`/`DROP COLUMN IF EXISTS` + 存在性守卫），中断后直接重试即可。
> V50 会把已有的目标分配关系自动迁入映射表并登记 `sys_schema_version`，**达成度核算数字与升级前逐位一致**；迁移前的标记行已整表备份到 `backup_ced_goal_marker_v50`。
> **V51 执行前置**：`docker compose pull` 后确认镜像已是 3.5.2（新代码不读该列）；V50 脚本尾部附有 GATE 对账 SQL（四项计数全 0 才安全），手动迁移时建议先跑一遍留档。

## 变更内容（v3.5.1 → v3.5.2）

### 修复

- **达成度矩阵「取消分配」根治重构**：目标分配/取消只增删映射表记录，不再物理删除考核明细行——杜绝「成绩成孤儿 → 达成度计算报错」的生产事故；一个考核点挂多个课程目标（M:N）成为一等公民
- **达成度计算健壮性**：历史遗留的孤儿明细（教师删除小题后的残留绑定）不再阻断整班核算
- **考试时间窗压秒提交竞态**：倒计时终点钳制到窗口截止时刻、后端提交闸门加时间窗容差，杜绝窗口边缘「自动交卷与手动提交」双触发
- **iOS 考试拍照链**：HEIC 照片双重有损压缩、对象存储直链占位符、双端并发空记录写库与空白冲答
- **Chrome < 109** 教学大纲（Word 模板预览含公式）渲染白屏：改为特性检测并提示升级浏览器
- **标准版构建**误带授权版水印

### 新功能

- **考试设备互斥**：同一学生多设备进入同场考试，后进者强制接管、先入端自动锁定，杜绝双端互写答案
- **代码题禁复制粘贴**：考试发布设置中按考试开启，学生端代码编辑器拦截复制/剪切/粘贴/右键菜单/拖入

### 界面优化

- 考试窗口截止提示显示具体日期与「已截止」状态
- 「按小题分配」编辑界面：序号/名称/题目数/分数四列等距排版
